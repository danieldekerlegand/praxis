## Codebase Patterns

- **The docs gates are a PAIR, and they live in three places that must stay in step:**
  `scripts/check-doc-links.mjs` (local references resolve — a **ratchet** vs the base) and
  `scripts/check-docs-structure.mjs` (index coverage · banners · closed directory set — a
  **wall**). Both are wired into `.chief/verify.sh` *and* `.github/workflows/ci.yml`.
  CLAUDE.md's "change one and change the other" rule applies: verify.sh + ci.yml + the
  guard's own header comment.
- **`chief verify` runs the MAIN CHECKOUT's `.chief/verify.sh`, not the worktree's.**
  Observed 2026-09-03: the header line reads
  `>> chief verify: /Users/dldekerlegand/Development/praxis/.chief/verify.sh (cwd=<worktree>)`.
  So a NEW step added to `.chief/verify.sh` inside a worktree is **not exercised by
  `chief verify` on that branch** — it only takes effect after the merge. Run the new
  check directly and say so in the story notes.
- **NEVER `git checkout .chief/state/prd.json`.** It is deliberately *uncommitted* runtime
  state; HEAD's copy is the PREVIOUS tasklist's finished PRD (all stories `passes: true`).
  I did this and clobbered 901's PRD with 900's. Recovery, should it happen again: the
  git-tracked `tasks/chief/<name>.json` is a byte-identical copy of the runtime PRD as
  installed, so `cp tasks/chief/<name>.json .chief/state/prd.json` restores it.
- **A gate is proved only on the rules you inject a violation for.** `check-docs-structure.mjs`
  landed in US-1 with four rules; two were never probed, and one of those (R2's
  "Superseded/Archived must say what replaced it") **could not fail** — it stripped an
  `^…$`-anchored regex from a joined multi-line string, so the banner text always survived and
  the emptiness test always passed. A clean-tree `OK` plus one unrelated injection proves
  nothing about the rule you care about. Probe each rule you add.
- **Backtick every `docs/...` path you name in a story's `notes`.**
  `scripts/check-doc-links.mjs` scans tracked JSON for bare `docs/...md` paths, and
  `tasks/chief/<name>.json` IS tracked — so a note describing a file you deliberately
  moved away from, or a violation you injected to prove a gate fires, registers as a
  doc-link REGRESSION and fails the merge. Observed: 3 dead references, all of them
  prose in my own notes. Backticks suppress it (the scanner's negative lookbehind).
- **Write JSON back with `ensure_ascii=False`.** Both the PRD and the tasklist are full of
  `—` and `·`; `json.dumps` defaults to escaping them and turns a 2-line edit into a
  whole-file diff.
- The documentation standard's home of record is
  `/Users/dldekerlegand/Development/rosetta/docs/reference/documentation-standard.md`
  (private repo — cite as backticked prose, never a relative link). Tier 1 root files:
  `README.md` `CLAUDE.md` `ROADMAP.md` `CHANGELOG.md` `LICENSE`, nothing else. Seven
  `docs/` dirs, a ceiling not a quota. R1 index · R2 banner · R3 archive-never-delete.

## US-3 — Archived, not deleted — and the record says why  (commit db7e5cb)

**Archived: one document. Deleted: none.** `technologies.md` →
`docs/archive/technologies.md`.

**Why `Archived` and not `Superseded`, and why that mattered.** It is the *original study
list* — the hand-written catalog praxis was built from. Its **what exists** half genuinely
has a successor (`docs/reference/curriculum.md` + `docs/explanation/gap-analysis.md`,
generated by `generate_docs.py`, so they cannot drift). Its **145 `_notebook not yet
written_` entries have no successor at all**: nothing live tracks them and `curriculum.py`'s
manifest does not contain them. Stamping it `Superseded` would have implied a replacement
that does not exist, and an archived doc quietly holding the only copy of a backlog is how a
backlog is lost. The banner says both halves explicitly.

**Measured, not asserted.** All **133** notebook links resolve — but **6 of the 145
"not yet written" entries are wrong today**: OWL, Finetune Tranformer LM, Model Context
Protocol, Agent-to-Agent, Agent Development Kit, ReAct all have notebooks. That is the whole
argument for archiving a hand-maintained catalog that sits beside a generated one, and it is
a number rather than an opinion.

**Repointed, not retargeted.** 133 links `notebooks/` → `../../notebooks/`. The *file*
moved, the tree did not; every link points at the same file as before, proved by
reconstructing the pre-move text and comparing (byte-identical) and by resolving all 133 from
the new location (0 dead). `check-doc-links.mjs` exempts `docs/archive/` as a **citer** to
stop an archived doc being edited to describe today's tree — that exemption is about
retargeting, and repairing a path the move broke is the opposite operation.

**The record: `docs/explanation/documentation-sweep.md`** — new, the docs half of what
`docs/explanation/dead-code-inventory.md` is for code. Method → what was archived → what was
left alone → **what was not verified** → the gates added. It also closes `900`'s Class E
handoff ("a document, not code … the docs sweep's call, not this one's") in writing, instead
of leaving a reader at that row with no answer.

**Left alone, deliberately** — decision records are history, not rot: `dead-code-inventory.md`
(rewriting its Class E row would falsify the work record), `jupyterquiz-assessment.md` (US-2

stay at the sizes the decision was taken on), the two generated docs (`generate_docs.py` →
zero-byte diff, re-confirmed), the two policy docs (`praxis.promote` / `praxis.refresh` import
and behave as documented), `notebooks/` and `tasks/chief/completed/`. Out of scope and
therefore *reported* rather than fixed: `ROADMAP.md`'s "the three storage backends".

### A gate I depended on was passing vacuously

`check-docs-structure.mjs`'s R2 clause "Superseded/Archived must say what replaced it" did
`lines.slice(first, first+3).join(' ').replace(BANNER, '').trim()`. `BANNER` is `^…$`-anchored
with **no `m` flag**, so it never matches a multi-line join; the banner's own text always
survived the replace and the emptiness test **could not fail**. That was the single rule US-3
exists to satisfy. Fixed to read the three lines *following* the banner.

US-1 reported that guard "proved to FIRE" and it had been — on R1 and R3, the rules it
injected violations for. **A gate is proved only on the rules you actually inject a violation
for.** Promoted to Codebase Patterns.

**Also added: R4, the Tier-1 root rule** US-1 deferred until the root was clean. Root markdown
is README / CLAUDE / ROADMAP / CHANGELOG / LICENSE and nothing else.

**Both proved by injection** — root `technologies.md` → 1 violation, exit 1; `Archived` banner
with nothing under it → 1 violation, exit 1; same file with a one-line note → OK, exit 0;
clean tree → `docs-structure: OK`, exit 0.

**Four descriptions updated in step** (CLAUDE.md's own change-one-change-the-other rule):
`CLAUDE.md`, `.chief/verify.sh`, `.github/workflows/ci.yml`'s header comment, and README's
gate table.

**Tree now:** 16/16 banner-stamped · 14 live subdocs all linked from `docs/README.md` plus 1
archived (exempt from R1, but linked anyway under a labelled **Archive** section so the
reasoning is findable) · 0 directories outside the standard's seven · 0 non-Tier-1 markdown at
the repo root.

**Gate** — `node scripts/check-docs-structure.mjs` → `docs-structure: OK`, exit 0 ·
`node scripts/check-doc-links.mjs` → `dead references 0 (0 distinct targets)` ·
`python3 -m praxis.gatefloor` → `coverage HOLDS` (live 117/245, 48%, 14 of 14 domains; floor
117/245) · `chief verify` → `verify: PASS`, **1205 passed, 1 skipped** in 477.18s, exit 0 —
identical counts to US-1's and US-2's.

**Learnings for future iterations**
- **A gate is proved only on the rules you inject a violation for.** Two of this guard's four
  rules were never probed; one of them could not fail. When you add a rule, probe *that* rule
  — a clean-tree `OK` and one unrelated injection prove nothing about it.
- **`Archived` vs `Superseded` is a factual claim, not a formality.** Use `Superseded` only
  when something actually replaced the document. If half of it was replaced and half was not,
  say both — the standard's banner permits "nothing did", and that sentence is the one a reader
  needs.
- **Moving a file breaks its relative links; that repair is not "editing an archived doc".**
  The archive exemption exists to stop retargeting at today's tree. Repoint, then prove the
  body byte-identical by reconstructing the pre-move text.
- **Defer a gate rule until the tree satisfies it, then land it in the story that cleans the
  tree.** US-1 → US-3 for R4 worked exactly as intended: no gate was ever red on arrival.
