Implemented the pinned nbgrader validation adapter in `praxis/checks.py`. Authored graded cells are staged and passed through `nbgrader validate` before release; executable solution/test regions are executed by nbgrader, manual Praxis extensions remain schema-valid, and actionable nbgrader failures return through the existing repair loop. Corrected checksums to nbgrader 0.9.5 semantics and made forced regeneration remove stale Praxis-owned graded cells. Added `scripts/validate_nbgrader.py`, wired it into `.chief/verify.sh` and `.github/workflows/ci.yml`, and documented the rubric/nbgrader responsibility split in `CLAUDE.md`.

Learnings for future iterations: nbgrader's CLI reports validation failures in output while retaining exit code 0, so the adapter must inspect its report.
