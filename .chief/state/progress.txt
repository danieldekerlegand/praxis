## Codebase Patterns

- **Grep the whole tree, not just code.** A naive `grep -E "praxis[./]<mod>"` reported
  `praxis/suggestion_review.py` as callerless; it has six callers reached through
  `from praxis import gap, jd_extract, suggest, suggestion_review`. Multi-name `from X import a, b`
  is the form that defeats a per-module regex. Use `git ls-files | xargs grep -n '\b<name>\b'`.
- **Count self-references too.** A definition-level scan that only counts *external* references
  reports every private helper. Requiring zero external AND zero in-file references cuts ~900
  candidates to 4.
- **`.chief/verify.sh` is path-scoped.** A change touching only `docs/explanation/*.md` runs the
  doc-link ratchet and nothing else. Touching any `.py`, `Makefile`, `README.md`, `scripts/` or the
  three version manifests pulls in `validate_nbgrader.py` + `praxis.gatefloor` + the full pytest run.
- **Commit, then `chief verify`.** The verdict is only recorded for a committed clean tree; the
  runtime `.chief/state/*` files count as dirt, so update them and commit before the final verify.

### Learnings for future iterations

- **The stranded-reference set was bigger than the inventory predicted.** US-1 listed six
  sites for `ralph/`; the actual grep after deletion found **eleven** — the extra five are
  docstrings that say "Ralph" without saying `ralph/` (`nbstatus.py:2,9`,
  `tests/test_notebooks.py:1,13`, `pyproject.toml:17`,
  `docs/explanation/notebook-rubric.md:6`). After any file removal, grep the *concept* name
  case-insensitively, not just the path. The inventory's A7 list is otherwise accurate.
- **`docs/explanation/gap-analysis.md` is generated, so its prose edits belong in
  `generate_docs.py` too** — edit both or the next `make docs` reverts you. Diff the file
  against a fresh `gen_gap_analysis()` before editing either.
- **Two live `generate_docs.py` defects found and deliberately NOT fixed** (behaviour
  changes, so they belong to 901): `main()` writes `docs/gap-analysis.md` while the tracked
  file is `docs/explanation/gap-analysis.md`, and `gen_gap_analysis()` omits the
  `> **Status:** …` banner the tracked file carries. Both recorded in the inventory.
- **The `.venv` does not exist in this worktree** — `python3` on PATH has the deps. `verify.sh`
  handles it; a bare `.venv/bin/python -m pytest` fails with "no such file or directory".
- **US-3 is a report, not a change.** Its raw material is already here: the undecidable class
  is what a static grep over *this* tree cannot see — a cross-repo consumer of `praxis/`
  (agora, chief), the `_RESOLVERS`/`_AVAILABLE` dispatch tables, `register_backend()`'s
  external seam, and names reached only through `getattr`/`importlib`/route decorators.
