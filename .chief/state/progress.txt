## Codebase Patterns

- **Grep the whole tree, not just code.** A naive `grep -E "praxis[./]<mod>"` reported
  `praxis/suggestion_review.py` as callerless; it has six callers reached through
  `from praxis import gap, jd_extract, suggest, suggestion_review`. Multi-name `from X import a, b`
  is the form that defeats a per-module regex. Use `git ls-files | xargs grep -n '\b<name>\b'`.
- **Count self-references too.** A definition-level scan that only counts *external* references
  reports every private helper. Requiring zero external AND zero in-file references cuts ~900
  candidates to 4.
- **`.chief/verify.sh` is path-scoped.** A change touching only `docs/explanation/*.md` runs the
  doc-link ratchet and nothing else. Touching any `.py`, `Makefile`, `README.md`, `scripts/` or the
  three version manifests pulls in `validate_nbgrader.py` + `praxis.gatefloor` + the full pytest run.
- **Commit, then `chief verify`.** The verdict is only recorded for a committed clean tree; the
  runtime `.chief/state/*` files count as dirt, so update them and commit before the final verify.

## US-1 — An inventory, measured before anything is removed (2026-09-03)

**Added:** `docs/explanation/dead-code-inventory.md` (250 lines). Nothing else changed; this story
deliberately removes nothing.

**Method (three passes, all reproducible from the doc):**
1. AST definition-level reachability over every tracked `.py` outside `notebooks/`, counting
   word-boundary hits in every tracked `.py .md .json .ts .tsx .rs .sh .mjs .html .toml .yml .css`
   file AND inside the defining file. Zero+zero = candidate.
2. Whole-file reachability for each top-level script and subsystem.
3. Duplication: hash every 8-line window of normalized non-blank non-comment Python lines.

### Learnings for future iterations

- **`chief/86` marked "delete the dead generators" as passing and did not delete them.** Both files
  are still in the tree and its `notes` restates the story premise instead of an observation. When
  US-2 removes them, the note must say what `git ls-files | wc -l` and the gate actually reported.
- **`ROADMAP.md:282` already declares `ralph/`/`.ralphy/` historical and superseded.** That is the
  repo's own evidence for the largest Class-A item, but removal strands `Makefile`'s `ralph` and
  `tasklists` targets, `README.md:124,305,345-353`, `curriculum.py:20`, `generate_docs.py:82` and
  `docs/explanation/gap-analysis.md:9`. Those edits belong in the SAME commit — the docs tasklist
  (901) is for docs that are wrong, not for references a removal strands.
- **The second-order check is the one worth running.** Re-running pass 1 with the Class-A files
  removed from the corpus produced the *same* four symbols and no new orphans, which is what proves
  nothing in `curriculum.py` or `praxis/` is kept alive only by the legacy scripts. Re-run it after
  each removal step in US-2.
- **US-2 should be several commits, one subsystem each** (AC: "reviewable steps rather than one
  sweep"): symbols+imports · legacy generators · sync_curriculum · ralph. Removing `ralph/` will
  touch `Makefile` and `README.md`, which pulls the FULL python gate in — budget for the pytest run.
